# Fondos de Filer

Tres imágenes generadas con la herramienta integrada ImageGen. Se conservan los PNG originales; el desenfoque de 18 px y la capa negra al 72% se aplican en CSS. El fondo cambia según la pestaña activa.

## filer-compression.png

Prompt final:

Use case: stylized-concept. Asset type: wide 16:9 desktop wallpaper used behind a dark personal image-compression utility. Create a polished cinematic abstract 3D scene of translucent photographic glass sheets and tiny luminous image pixels being gently gathered into a compact crystalline stack, an elegant visual metaphor for image compression. Deep navy and charcoal space, cool blue and cyan glows, subtle silver highlights. Main forms toward outer thirds, generous quiet center for UI. Soft atmospheric depth of field and restrained bloom, sophisticated low contrast, recognizably dimensional, no text, no letters, no numerals, no logos, no UI, no watermark. It will receive additional CSS blur and black overlay; keep attractive large shapes visible. Landscape wallpaper, not a screenshot.
